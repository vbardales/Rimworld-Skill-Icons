# SkillIcons

A unified passion icon set for Vanilla Skills Expanded and Alpha Skills, with optional subtle animations in the Bio skill list.

## Runtime behavior

- Animated icons are shown through Vanilla Skills Expanded's `PassionDef.Icon` and `WorkBoxIcon` properties.
- The Bio skill list and Work tab currently use the same animation speed.
- If an animation sequence is absent, the normal static icon is used automatically.
- Animations can be disabled and their speed adjusted under **Options > Mod settings > SkillIcons**.

## Load order

Load after Harmony, Vanilla Skills Expanded, Alpha Skills and Oracle's Skill Icon Retextures.

## Development

Source code and SVG sources are stored under `_tools/`. Runtime files are under `1.6/`.
