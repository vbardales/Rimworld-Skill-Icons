# Attribution

Every texture in this mod is generated by `_tools/gen.js` and ships under the MIT
licence in `LICENSE`. No asset is copied from another mod. What follows is what
the mod nevertheless owes to others, and the one place where it reads someone
else's files without redistributing them.

## Oracle's Skill Icon Retextures — the visual language

Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3214465250

This set follows Oracle's idea: a heart carrying one small mark that says which
passion it is. That grammar is theirs, and this mod would look nothing like it
without them. **The artwork is not.** Early drafts did build on their files;
nothing of that survives — the 85 passion textures, including the seven
vanilla/VSE ones, are drawn from scratch by the generator.

The mod declares Oracle's mod in `loadAfter` for a purely technical reason: both
sets write to the same texture paths, and whichever loads last wins.

## Vanilla Skills Expanded — Oskar Potocki, Sarg Bjornson, Taranchuk

Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3400246558

`PassionDef` is theirs. Without it there would be no passions to draw beyond
vanilla's two, and no `iconPath` to override. This mod patches
`WidgetsWork.DrawWorkBoxBackground` after them, by explicit Harmony ordering.

`1.6/Patches/VSE_Fixes.xml` adds a missing `workBoxIconPath` to `VSE_Apathy`.

## Alpha Skills — Sarg Bjornson

Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3448953006

The twenty-six circumstantial passions this set spends most of its drawings on.
`1.6/Patches/AlphaSkills_Fixes.xml` repairs four def mistakes found while reading
them: a description copy-pasted from another passion, a missing "(active)"
label, a missing work tab icon, and two blindness tiers sharing one icon despite
granting different bonuses. The patch sits in a `<success>Always</success>`
sequence, so if Sarg fixes them upstream it goes quietly inert.

## Pawn Badge — (MISC) Job Icons+ Revitalized

Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3524906267

When that mod is installed, this one **reads its textures at runtime** through
`ContentFinder`, so that a player already using those badges sees one consistent
interface. Nothing is copied into this mod and nothing is redistributed: remove
that mod and the icons fall back to ours, silently.

The mapping lives in `SkillTypeIcons.cs` and was written by looking at the
icons, not by reading their file names, under one rule — map when the icon
*means* the same thing, never when it merely resembles it. `drugs` is a capsule
that would suit "Patient" perfectly, but in the source pack it means an addict;
serving it as the Patient column would plant in the player's own interface the
confusion this mod exists to remove. Patient therefore keeps our drawing, as do
Basic work, Childcare and Dark study, which the pack does not cover at all.

## Removal

If any author listed here would rather this mod did not follow, credit, or read
from their work, say so and it will be changed or withdrawn.
