A unified passion icon set for [Vanilla Skills Expanded](https://steamcommunity.com/sharedfiles/filedetails/?id=3400246558) and [Alpha Skills](https://steamcommunity.com/sharedfiles/filedetails/?id=3448953006).

## Passions

Two rules govern the whole set. **Hue is identity**: every passion owns a hue of its own, spread right across the colour wheel, and that hue is carried by the main shape rather than by a small accessory - at 24 px an accessory simply disappears. Lightness and saturation say whether the bonus is live or dormant, and dormant is neutral grey rather than a colour of its own. And every icon is meant to be recognisable as a plain black silhouette, so the work tab stays readable once colour is gone - its grey variants use two greys instead of one.

Forty of them animate, and each gesture says something about the passion rather than wobbling generically: the padlock opens, the pendulum swings, the signal runs the circuit, the sand drains and stays drained.

## The work tab

The work tab is where the grid is hardest to read, so it gets its own controls: passion icons drawn in colour, greyed, or - the default - in colour while the bonus is actually running and grey while it sleeps. Size and opacity are separate sliders, because size helps you see the passion while opacity gives the priority digit back to the text.

## Options

Options > Mod settings > Skill Icons:

- subtle animations, on by default, with a speed slider
- the three work tab modes, plus size and opacity
- an optional faint icon for "no passion", off by default
- a gallery of every passion, animating live, so you can see the whole set without starting a colony

A hidden MainButtons shortcut is also supplied for [RIMMSQOL](https://steamcommunity.com/sharedfiles/filedetails/?id=1084452457) and compatible customization mods. It is neither visible nor greyed out by default.

## Def fixes

It also repairs a couple of remaining def mistakes.

In [Alpha Skills](https://steamcommunity.com/sharedfiles/filedetails/?id=3448953006): the two degrees of "blind" get separate icons here despite sharing one upstream (Sarg's own intentional design - kept as this set's own choice, since every other passion carries its own hue). Three earlier fixes for a copy-pasted "nudist (active)" description, a mislabelled "pain-driven (active)" and a missing "frozen" work tab icon are no longer needed: Sarg fixed all three upstream within a day of being asked.

In [Vanilla Skills Expanded](https://steamcommunity.com/sharedfiles/filedetails/?id=3400246558): "apathy" had no work tab icon.
